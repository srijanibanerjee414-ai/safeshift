SafeShift is a high-tech industrial safety dashboard and futuristic disaster relief portal engineered with a sleek, dark-mode industrial-sci-fi aesthetic. It provides real-time situational awareness, autonomous antigravity stretcher tracking, zero-emission heavy wreckage clearance logistics, and quantum weight-nullification safety compliance monitoring.

---

## Key Modules & Interactive Capabilities

### 1. Zero-Gravity Rescue Dispatch
- **Interactive Tactical Disaster Grid (Sector 7):**
  - High-DPI canvas topographic contour mapping of collapsed laboratories, rubble mounds, and staging depots.
  - Animated 360° rotating radar sweep line with distance scale calibration.
  - Interactive casualty beacon distress signals with triage categorization.
  - Vector flight corridors with active antigravity hovering halos.
  - Hover coordinate HUD displaying real-time Latitude, Longitude, and Elevation.
- **Real-Time Patient & Transport Telemetry:**
  - Dynamic 60 FPS electrocardiogram (ECG) waveform canvas tuned to patient heart rate.
  - **Zero Jostle Index gauge** maintaining `< 0.0025 G` with 99.88% inertial cancellation.
  - Elevation lock gauge (`1.45m ± 0.005m`), SpO2, blood pressure, core temperature, and gyro tilt.
- **Antigravity Stretcher Fleet Controls:**
  - Status filters (`ALL`, `EN ROUTE`, `EVACUATING`, `STANDBY`).
  - Quick action modal to toggle levitation damping presets (*Spinal Rigid Active*, *High-Speed Glide*, *Zero-G Isolation Pod*) or issue emergency recalls.

### 2. Debris Clearing Dashboard
- **Logistics Performance Metrics:**
  - **Total Tonnage Cleared**: Animated ticker continuously incrementing as active beams lift wreckage.
  - **Carbon Emissions Saved**: Real-time comparison against Tier-4 diesel cranes (0.27 MT CO₂e saved per ton lifted).
  - **Active Lift Fields**: Field utilization ratio and superconducting grid draw (`MW`).
- **Gravity-Nullification Chamber Simulation:**
  - Visual canvas rendering upward energy emitter cones, ascending harmonic wave rings, levitating rebar/concrete slabs, and upward-floating anti-gravity dust particles.
- **Interactive Sector Controls:**
  - Sectors Alpha-1 through Epsilon-4 with priority badges (*Critical*, *Moderate*, *Clear*).
  - Power toggle switches to engage/disengage nullification beams.
  - Interactive flux intensity sliders with instant live calculation of apparent effective weight.
  - **Harmonic Frequency Tuner** (432 kHz to 512 kHz) to prevent vibrational resonance damage to surrounding structures.

### 3. Industrial Weight-Nullification Tracker
- **Cargo Weight vs. Apparent Handled Weight Monitor:**
  - Real-time comparison: a raw gravitational mass of **`5,000 kg`** (`49,050 N`) is reduced by `99.999%` nullification field efficiency to an apparent human handled weight of **`0.050 kg (50 grams)`** (`0.49 N`).
  - Musculoskeletal spine compression meter showing `0.01% of standard safe limit` with human exertion metaphors.
  - Interactive presets: 5-Ton Steel I-Beam, 20-Ton Precast Wall Slab, 45-Ton Container, 2.8-Ton Generator, plus a continuous custom slider (100 kg to 50,000 kg).
- **Worker Safety Exoskeleton Roster:**
  - Live biometric telemetry (heart rate, fatigue index, active carried load, apparent handled weight).
- **Crushing Hazard Interlocks:**
  - Proximity warning indicators with auto-braking deceleration interlocks.
  - Interactive **"Test Safety Hazard Drill"** button simulating sudden inertial decoupling drills.
- **OSHA & ISO-9001-Q Compliance Audit Logs:**
  - Automated timestamped verification of all weight-nullified operations.
  - Modal with printable certificate view.

### 4. Auditory Feedback Synthesizer
- Procedurally generated Web Audio synthesizer (no external audio assets required).
- Custom sci-fi sound effects for tactile clicks, quantum deployment chords, gravity beam hums, and hazard sirens.

## Technology Stack
- **HTML5 & Vanilla JavaScript**: Modular architecture with sub-engines for telemetry, tactical mapping, debris logistics, and weight nullification.
- **Tailwind CSS**: Dark-mode industrial theme (`charcoal-950`, `neon-cyan`, `neon-amber`, `neon-emerald`, `neon-rose`).
- **Lucide Icons**: Crisp vector icons.
- **Web Audio API**: Browser-native sound synthesis.
- **HTML5 Canvas**: Hardware-accelerated 60 FPS graphics.

## Quick Start
1. Clone this repository:
   ```bash
   git clone https://github.com/srijanibanerjee414-ai/safeshift.git
   ```
2. Open `index.html` in any modern web browser, or launch a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
3. Navigate to `http://localhost:8000`.
